# ✨ Celeste Royale – Luxury Hotel & Resort Website

Celeste Royale is a **responsive full-stack web development project** that showcases a premium **7-star luxury hotel and resort**. The website delivers a modern user experience with elegant design, smooth navigation, and dedicated pages for accommodations, events, bookings, and hospitality services.

---

## 🌟 Features

### 🏨 Hotel Experience

* Elegant homepage with luxury branding
* About page introducing the resort
* Luxury Rooms & Suites
* Online booking page
* Contact page
* Responsive navigation

### 💍 Hospitality Services

* Wedding & Event venues
* Fine Dining & Café
* Spa & Wellness
* Infinity Pool
* Luxury Interiors
* Gallery showcasing hotel facilities
